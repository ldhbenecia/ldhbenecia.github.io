# 작업 시작 체크리스트

이 레포에서 새 작업을 시작할 때 다음 순서로 컨텍스트를 잡는다.

1. **구조 파악** — [README.md](../../README.md) 의 Structure
   - 이력·프로젝트·수치는 `content/` 에만 있다. 컴포넌트에 문구를 하드코딩하지 않는다
   - 섹션은 `components/sections/`, 섹션 전용 스타일은 같은 이름의 `.module.css`
   - 색·서체·간격·모션 토큰은 `app/tokens.css` 한 곳
2. **관련 결정 확인** — [docs/adr.md](../../docs/adr.md)
   - 팔레트, 서체, 하우스 룰(그라디언트·그림자·아이브로 라벨·모노스페이스 금지 등)은 ADR로 정해져 있다.
     **결정과 어긋나는 구현을 하지 않는다**
3. **세부 룰 떠올리기** — [.claude/rules/](.) — 주석·커밋·ADR 규칙

## 콘텐츠를 고칠 때

- 수치는 이력서·레포 README·실측 기록에 근거가 있는 것만 쓴다. 추정치·반올림한 과장 금지
- 제목(h1~h3)은 모든 화면 폭에서 두 줄 이하

## 코드를 고치기 전에

- **참조를 먼저 확인한다.** 삭제·리네임은 `grep -rn` 으로 사용처를 전부 확인한 뒤에
- 화면을 바꿨으면 1440 / 768 / 390 폭에서 직접 확인한다
